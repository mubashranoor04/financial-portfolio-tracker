# Financial Portfolio Tracker

A Spring Boot and JPA-based application for managing financial advisors, clients, portfolios, and investment securities.

## Features

* Manage Financial Advisors
* Manage Clients
* Create and Manage Portfolios
* Add, Update, and Remove Securities
* Relational Database Storage using JPA
* Spring Framework Backend

## Data Model

* Financial Advisor
* Client
* Portfolio
* Security

## Technologies

* Java
* Spring Boot
* Spring Data JPA
* Relational Database
* Git & GitHub
